	\section*{Introduction}
	
		\subsection*{Purpose}
	
			\paragraph{} Our goal when creating this project was to make a spending tracking tool we would actually use. This web app is a place where purchases can be stored, recalled, and analyzed. We didn't like modern budgeting apps with the extra fluff of telling you where and how your money should be spent. The idea of something smaller and specialized created this spending tracker, where the only goal is to store where your money is spent. We track what you spent money on categorically, as well as the amount, the location, the time and data, the medium of payment, and whether or not it was spent online. This allows for analytics to be generated that show your spending habits in a digestible format.
	
		\subsection*{Scope}
		
			\paragraph{} The scope of this project is intentionally narrow. We did not intend to compete with bigger budgeting apps who have more features and better analytics. Our sole goal was to create a centralized ledger and analysis tool to show you where your money ends up. This required the creation of one tool, the web app itself. Included in this are portions to log in, view enter new purchases, and look at analytics for past purchases.
		
		\subsection*{Details}
		
			\paragraph{} This project has a relatively straightforward 'how'. It is a server hosted web application, hosted in our basement on Ubuntu server. The app uses flask for the web framework to keep everything simple and light. The backend database is hosted on Microsoft SQL Server 2025. Plotly was used for the creation of all the graphs and charts. Implementation of the login system is done with cookies, as modern pages do.
